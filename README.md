# Campus Pulse 🎓

A modern full-stack campus management platform designed to streamline student communication, announcements, events, and academic updates through an interactive dashboard interface.

---

## Technologies

### Frontend

* React
* Vite
* TypeScript
* Tailwind CSS
* React Router DOM

### Backend

* Node.js
* Express.js
* MongoDB

---

## 📦 Features

* 📢 Campus announcements
* 📅 Event management
* 👩‍🎓 Student dashboard
* 🔔 Real-time notifications
* 🔐 Secure authentication
* 📱 Responsive UI

---

## 🛠️ Setup & Installation

### Clone Repository

```bash
git clone https://github.com/Varsshini04/campus-pulse.git
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
npm install
npm start
```
